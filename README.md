# 第一部分 公理与形式基础

## 第 1 章 公理起点

一切推导的唯一起点。以下公理不可再分解。

| 编号 | 公理 | 陈述 |
|---|---|---|
| AX1 | 实数完备性 | ℝ 是完备有序域（Cauchy 收敛） |
| AX2 | 复数域 | ℂ = {a+bi : a,b∈ℝ}，i²=-1；ℂ 上内积 ⟨z,w⟩ = Σ z̄·w（**共轭线性于第一参数**） |
| AX3 | 神经束对称性（**本重构第一性原理**） | 神经束网络是 D 个信息载体 {u_i}，其物理意义不依赖于编号 i 的**循环重排**。对循环移位 T（生成循环群 C_D），动力学 f 满足 f(T·u) = T·f(u)。**非任意置换**——对称群是 C_D 而非 S_D（见 §3.1 T-GR-1 裁定） |
| AX4 | 信息混合必要性 | 神经束间必须存在非平凡信息混合（否则 D 个载体独立演化，无法形成网络） |
| AX5 | 信息携带 | 每个神经束同时携带"强度"（幅值）与"类别/方向"（相位）——信息需复数编码 |
| AX6 | 耗散性 | 无外部驱动时系统能量单调不增（物理上不可逆） |
| AX7 | 序列演化 | 状态在时间维（序列 S）上递推传播，允许长程依赖压缩 |
| AX8 | 路由可微 | 内容到子空间的分配必须是利普希茨连续的软分配（Cauchy-Lipschitz 适定性） |
| AX9 | 边界自由 | 输入/输出边界（域不同）无对称性要求，允许自由投影（T-BOUND-1，§3.1） |
| AX10 | 离散实现 | 所有连续对象以离散化形式实现，稳定性判据必须在离散域验证（CFL/谱半径） |

**AX3 裁定说明**：早期文档主张对称群为 S_D（任意置换）。但群表示论（T-GR-1）表明：ℂ^D 上交换于 **S_D** 的线性算子只有标量 λI——非平凡线性混合在 S_D 等变下不存在，与 AX4 矛盾。**循环群 C_D 是唯一使"混合"与"等变"同时成立的对称群**：可交换于 C_D 的线性算子恰为循环矩阵（频域对角乘子，T-GR-2），完备且非退化。故公理取 C_D。

# 第二部分 算子层理论（单模型内部等变结构）

## 第 3 章 群等变理论基础

### 3.1 循环等变线性算子的完全刻画

**定理 T-GR-1（S_D 等变退化）**：
ℂ^D 上可交换于**所有**置换矩阵 P ∈ S_D 的线性算子 L 必为标量 λI。
*证明*：S_D 的 D 维不可约表示分解——标准表示 ℂ^D = 平凡⊕标准；Schur 引理：与所有表示矩阵交换的算子在各不可约块上为标量；平凡块与标准块的标量系数相等（因为 (1,1,…,1) 的像被等变约束）。故 L = λI。∎
*推论*：**S_D 等变下非平凡线性混合不存在**——这就是必须取 C_D 的数学理由（AX3 裁定）。

**定理 T-GR-2（循环等变 = 循环矩阵 = 频域对角，核心定理）**：
线性算子 L: ℂ^D→ℂ^D 循环等变（L T = T L）⟺ L 是循环矩阵 ⟺ 存在 W ∈ ℂ^D 使 L = F⁻¹ diag(W) F。
*证明*：
(⟸) diag(W) 与任何对角无关；F⁻¹ diag(W) F 是循环矩阵（Toeplitz），与 T 交换：T = F⁻¹ diag(λ_k) F（DFT 对角化移位，λ_k = e^{2πik/D}），故 L T = F⁻¹ diag(W)diag(λ)F = F⁻¹ diag(λ)diag(W)F = T L。∎
(⟹) L 与 T 交换 ⟹ L 保持 T 的每个特征空间（DFT 基向量 e^{(k)}），因 T 的特征值 λ_k 互异（D 个不同 D 次单位根）⟹ 每个特征空间一维 ⟹ L e^{(k)} = W_k e^{(k)} ⟹ 在 DFT 基下对角。∎
*意义*：**频域乘子 W_k 是 C_D 等变线性混合的完整参数化——不多（所有等变线性算子都是这个形式），不少（无遗漏）**。参数依赖频率 k 而非索引 i，符合"编号不相关"公理。

**定理 T-GR-3（FFT 酉性）**：归一化 DFT 酉：F⁻¹ = F^†，‖Fu‖ = ‖u‖（Parseval）。
*证明*：DFT 矩阵 F_{k,i} = D^{-1/2} e^{-2πiki/D} 是酉矩阵（正交行）。‖Fu‖² = u^†F^†Fu = u^†u。∎
*推论*（能量定理 T-ENE-1）：‖L^W u‖² = Σ_k |W_k|² |(Fu)_k|² ≤ (max_k|W_k|)²‖u‖²——频域乘子的能量比 = max_k|W_k|（离散单步压缩判据）。

**定理 T-GR-4（等变逐元函数）**：逐坐标相同函数 g: ℂ→ℂ（(gu)_i = g(u_i)）对 C_D 等变。modReLU（T-ACT-1）与全局复数归一化（T-NORM-1）均属此类。

**定理 T-BOUND-1（边界自由）**：输入适配 A: X→ℂ^D 与输出观测 O: ℂ^D→Y 是边界映射（定义域/值域无神经束对称结构），不参与 C_D 等变约束；允许任意线性投影。中间层（ℂ^D→ℂ^D 内）必须满足 T-GR-2/T-GR-4。
*裁定*：输入空间对称性**不立公理**（输入不确定，内部对称才是公理域）；输入/输出同为边界层，允许自由投影。输入空间的物理坐标（如像素位置）必须由数据定义，与神经束对称性无关。**位置信息必须在边界内转化为内容/序列结构**（接入层三模式 / 输出层三头，见 §4.1/§4.8），禁逐索引参数入内部。

### 3.2 参数化约束定理

**定理 T-PAR-1（等变参数化清单，工程红线）**：C_D 等变网络中，可训练参数只允许以下三种形态：
1. **频域乘子** W_k（依赖频率 k，T-GR-2 唯一线性混合）
2. **全局标量**（b_g, c, α, β, w_N 等，所有神经束共享）
3. **内容锚点** e_j（路由代价只依赖内积 ⟨u_i, e_j⟩，每个 i 独立处理，天然等变）
任何依赖神经束索引 i 的矩阵参数（W_ij、对角 γ_i 等）破坏等变，禁止（T-GR-1）。
*证明*：逐项验证——频域乘子（T-GR-2）、标量（T-GR-4 特例 g(z)=sz）、锚点（代价 c_ij 只依赖 u_i 自身与公共锚点，置换/循环重排下逐 i 不变）。∎
*边界例外*：输入/输出层（T-BOUND-1）允许 nn.Linear 与逐索引参数。

## 第 4 章 复数算子库（形式化定义 + 推导）

### 4.1 O0' 输入适配（边界层，自由投影）

**定义**：A: ℝ^{d_in} → ℂ^D，u^0 = A(x)。**接入层三模式**（T-BOUND-1 自由域）：
- **模式 I 复数卷积**：图像域正解——复数卷积提取局部结构先验（平移鲁棒，C-416 实证 47.23% > patch 38.21%）
- **模式 II 复数嵌入**：文本/序列域——复数词嵌入查表（C-415 实证 ppl 落后 GPT2 2.1×，文本域待深化：SSM 状态容量/文本标定）
- **模式 III 集合投影**：通用降维/升维投影（当前 C-413 为 3072→128）
**约束**：无等变约束（T-BOUND-1）；但输出必须进入神经束空间（后续层等变）。

### 4.2 O1' 复数 FFT 谱扩散（信息混合，T-GR-2 实现）

**定义**：
$$u_{\text{feat}} = \mathcal{F}^{-1}\big(W_k \odot \mathcal{F}(u)\big), \quad W_k \in \mathbb{C}, \ \text{Re}(W_k) \le -\gamma$$
其中 F 为**全复数 DFT**（非 rFFT——输入是复数，rFFT 只对实输入有效，丢弃虚部信息，废弃）。

**推导链**：
- 混合需求（AX4）+ 等变公理（AX3）→ 唯一线性实现 = 循环等变算子（T-GR-2）= 频域对角乘子
- 耗散需求（AX6）→ Re⟨L^W u, u⟩ = Σ_k Re(W_k)|(Fu)_k|²/D ≤ 0 ⟺ Re(W_k) ≤ 0 逐 k（复内积，T-SG-1）
- 离散单步压缩（AX10）→ 能量比 = max_k|W_k| ≤ 1（T-ENE-1）→ |W_k| ∈ (0,1]，Re(W_k) ∈ [-1, -γ]

**约束**（每步 enforce）：Re(W_k) ∈ [-1, -1e-3]；|W_k| ≤ 1（模长裁剪，Parseval）。
**复杂度**：O(D log D)（复数 FFT）。
**测试锚点**：‖F u‖ = ‖u‖（T-GR-3）；f(Tu) = T f(u)（T-GR-2 数值验证）；能量比 ≤ 1。

### 4.3 O2' modReLU（复数激活，T-ACT-1）

**定义**：σ(z) = ReLU(|z| + b) · z/|z|，b ∈ ℝ 可学习标量（Arjovsky 2016）。
**性质**：
- 相位保持：arg σ(z) = arg z（z/|z| 是单位相位）✓（PV-03 验证）
- 幅值非线性：|z|+b 过 ReLU（0 处软阈值）
- C_D 等变（逐元相同函数，T-GR-4）
**推导**：实数 ReLU 无法定义于 ℂ（无全序）；复数激活的最小相位保持推广即 modReLU。

### 4.4 O3' 复数归一化（T-NORM-1）

**定义**：u ← u / √(E[|u|²] + ε)（全局模长归一化，标量缩放）。
**性质**：无逐索引参数（γ_i 破坏等变的根源，废弃 LayerNorm）；C_D 等变（T-GR-4）。
**与 LayerNorm 对比**：LN 的逐特征 γ_i 是逐索引参数（T-PAR-1 禁止）；纯归一化（无 γ）虽等变但无缩放学习能力——复数归一化以全局标量缩放补偿。

### 4.5 O4' 复数 Sinkhorn 路由（内容自适应分配，AX8）

**定义**：
$$\pi_{t,i,j} = \text{Sinkhorn}_{\lambda}\left( 1 - \frac{\text{Re}\langle u_{t,i}, e_j\rangle}{|u_{t,i}| \cdot |e_j|} \right)$$
e_j ∈ ℂ^{d_a} 复数锚点；⟨u,e⟩ = Σ ū·e（共轭点积，**实部**是实数相似度）。

**性质**：
- 等变：代价只依赖 u_i 与公共锚点（逐 i 独立），C_D 等变 ✓
- 软分配规范：π ∈ Δ^G（**沿槽维行和=1**，逐位置单边际熵正则 OT，闭式 log-softmax）；双随机（1/G 边际）仅限严格均衡模式
- 利普希茨连续（AX8，Cauchy-Lipschitz 适定性）：Sinkhorn 映射对代价扰动是利普希茨的（熵正则保证光滑性，常数 ∝ 1/λ）
- 定理：Birkhoff-von Neumann（双随机 = 置换凸组合）、Sinkhorn 指数收敛（10 迭代 ~1e-2）
- **Hopfield 同构（显式，§21.4）**：π = softmax(β·cos(u_i, e_j))，β = 1/λ——与 Hopfield 检索概率同构

### 4.6 O5' 复数多槽 SSM（序列演化，AX7）

**完整定义（N ≥ 1，统一 N=1 简化形态与 N>1 完整形态）**：

$$h_t^{(g)} = A_g \odot h_{t-1}^{(g)} + b_g \odot \big(\bar{u}_t^{(g)} \cdot \mathbf{1}_N\big), \quad A_g, b_g \in \mathbb{C}^N, \ A_g \text{ 对角冻结}, \ |A_g| \le 1$$

$$u_{\text{seq},t,i} = c \cdot \sum_{g=1}^{G} \pi_{t,i,g} \cdot \big(w_N^{\top} h_t^{(g)}\big), \quad c \in \mathbb{C}, \ w_N \in \mathbb{C}^N \text{ 全局共享}$$

其中 ū_t^(g) = Σ_i π_{t,i,g} u_{t,i}（槽聚合，沿束维标量加权和——等变）。

- **N=1 简化形态**（早期实现）：b_g, c ∈ ℂ 标量，w_N 退化为 1，原式还原为
$$u_{\text{seq},t} = c \cdot \sum_{g=1}^{G} \pi_{t,g} \cdot h_t^{(g)}, \quad c \in \mathbb{C}$$
- **N>1 完整形态**：输入广播（标量 ū 乘 𝟙_N 驱动各状态通道）+ 读出映射 w_N（N 维状态 → 标量）
- **参数形态**：A_g（冻结）/b_g 按槽 g 与状态维 n 索引；w_N 全局共享（跨槽跨束）——**均不依赖神经束索引 i**（合规论证见 §21.2：状态维 N 是内部时间记忆通道，非束索引）

**等变论证**：SSM 的输入输出均为聚合后的标量流（逐槽），不出现神经束索引耦合；A 对角逐元素乘（同函数），b/c/w_N 共享。✓
**稳定性**：|A_g| ≤ 1（谱半径，相移矩阵初始化为主路径——T-HIPPO 降级备选，见 §12 修订总表）；状态压缩误差与 S 无关（长程记忆保证）。
**状态显存**：G×N 复数，与 S 无关（推理期恒定，沿用核心卖点）。
**冻结约束**：A_g 冻结（物理时间演化常数；训练 A 破坏长程记忆保证）。

### 4.7 O6' 复数融合残差

**定义**：u_out = α·u_feat + β·u_seq + u_residual，α, β ∈ ℂ（标量门控）。
**约束**：残差缩放 |α|²+|β|² ≤ 1/2 变体（复数版防范数爆炸，能量分析：‖αu_f+βu_s+u_r‖² ≤ (|α|‖u_f‖+|β|‖u_s‖+‖u_r‖)²，需联合约束；工程取 |α|,|β| ≤ 1/√2 初始）。

### 4.8 O7' 输出观测（边界层，唯一允许投影处）

**定义**：**输出层三头**（T-BOUND-1 自由域）：
- **判别头**：u_mag = |u_out| ∈ ℝ^D（模长，相位丢弃）；任务头 W_task: ℝ^D → ℝ^K（nn.Linear 允许）

- **图像生成头**：patch 序列生成

## 第 8 章 定理 DIS-1：锚点分离保持（对裂缝 1）

### 8.1 陈述

**设定**：锚点集 E = {e_j}_{j=1}^G ⊂ ℝ^d 在连续时间梯度流下训练：

$$\frac{de_j}{dt} = -\nabla_j L, \quad L = L_{\text{task}} + \mu \cdot R_{\text{sep}}$$

其中 L_task 为任务损失（经 Sinkhorn 路由间接依赖锚点），R_sep 为排斥正则，μ > 0 为排斥强度。

**假设**：
- **(H1) 任务损失锚点光滑性**：∃ L_1 > 0 使对任意 j ≠ k：‖∇_j L_task − ∇_k L_task‖ ≤ L_1·‖e_j − e_k‖（梯度联合利普希茨）
- **(H2) 近域排斥**：R_sep 含对数排斥势 ρ = −Σ_{j<k} log‖e_j − e_k‖，其梯度差对 (j,k) 对贡献 Re⟨e_j−e_k, ∇_j ρ − ∇_k ρ⟩ = −2（精确）
- **(H3) 主导排斥**：对**全局最小距离对** (j*,k*)，其余锚点的梯度差贡献不抵消近域排斥主导（第三锚点交叉项并入常数修正）——严格化多锚点情形

**定理（DIS-1）**：在 (H1)(H2) 下，任意锚点对 (j,k) 的分离度 r(t) = ‖e_j(t) − e_k(t)‖ 满足

$`r(t) \ge \min\left\{r(0),\; \sqrt{2\mu / L_1}\right\} \quad \forall t \ge 0`$

即**锚点永不坍缩**（r → 0 不可能），且分离度下确界 ≥ min{初始分离度, √(2μ/L_1)}。

### 8.2 证明

对锚点对 (j,k) 计算分离度平方的时间导数：

$$\frac{d}{dt} r^2 = 2\langle e_j - e_k,\; \dot{e}_j - \dot{e}_k \rangle = -2\langle e_j - e_k,\; \nabla_j L - \nabla_k L \rangle$$

拆为任务项与排斥项：

$$\frac{d}{dt} r^2 = \underbrace{-2\langle e_j-e_k,\; \nabla_j L_{\text{task}} - \nabla_k L_{\text{task}} \rangle}_{\text{(T)}} \underbrace{- 2\mu\langle e_j-e_k,\; \nabla_j R_{\text{sep}} - \nabla_k R_{\text{sep}} \rangle}_{\text{(S)}}$$

**排斥项 (S)**：由 (H2)，ρ 的梯度差为 ∇_j ρ − ∇_k ρ = −2(e_j−e_k)/r²，故

$$(S) = -2\mu \cdot (-2) = 4\mu > 0$$

（对数势在近域提供恒定的分离推力 4μ，方向正确。负号来自 ρ 定义的前缀负号——这是证明的关键。）

**任务项 (T)**：由 (H1)：

$$|(T)| = 2|\langle e_j-e_k,\; \nabla_j L_{\text{task}} - \nabla_k L_{\text{task}} \rangle| \le 2 \cdot r \cdot L_1 r = 2L_1 r^2$$

**合并**：

$$\frac{d}{dt} r^2 \ge 4\mu - 2L_1 r^2$$

**比较论证**：定义危险区 W = {r² ≤ 2μ/L_1}。在 W 内：d/dt r² ≥ 4μ − 2L_1 r² ≥ 0（当 r² = 2μ/L_1 取等，r² < 2μ/L_1 时严格正）。因此：
- 若 r(0) ≥ √(2μ/L_1)：轨迹从上方接近 W 边界时，d/dt r² → 0⁺，不能进入 W 内部；r(t) ≥ √(2μ/L_1)
- 若 r(0) < √(2μ/L_1)：r(0) ∈ W 且 W 内 d/dt r² > 0，分离度单调增长直至离开 W

两种情况均有 r(t) ≥ min{r(0), √(2μ/L_1)}。∎

### 8.3 推论与工程意义

- **推论 DIS-1a（坍缩判据）**：锚点坍缩的必要条件是 L_1/μ ≥ 2/r²——**排斥强度 μ 必须超过任务损失的锚点利普希茨常数**（与分离度平方成反比）。工程红线：μ 的正交正则强度不能拍脑袋取，必须与 L_task 的光滑性匹配。
- **推论 DIS-1b（λ-μ 联动）**：Sinkhorn 映射的利普希茨常数 ∝ 1/λ（AX8 利普希茨连续性），故 L_1 = O(1/λ)。**λ 退火（冷启动 10→0.1）会放大 L_1，必须同步增强排斥正则 μ 以维持分离保证**——否则退火后期锚点坍缩风险上升。这把离散审计附加风险（λ→0 利普希茨发散）与裂缝 1 统一为同一判据。
- **推论 DIS-1c（初始化必要性）**：定理只保分离下界，不保初始分离——**正交/均匀相位初始化是定理前提 r(0) > 0 的工程保障**。

### 8.4 置信度

**A/B 级**：比较论证本身为纯微分不等式 + 比较原理 + Gronwall 类论证（A 级；引用 Gronwall 1919）；但整体定理依赖 **(H3) 主导排斥假设**（交叉项 ≥ 0 的经验成分，需数值确认）与 (H1) 的 L_1 实测值——综合标注 **A/B 级**（纯数学 A + 经验假设 B）。

## 第 9 章 定理 DIS-2：骨架容量（对裂缝 3）

### 9.1 陈述

**设定**：Sinkhorn 路由（§4.5 O4'），代价 c_{ij} = 1 − cos(u_i, e_j)，温度 λ > 0，软分配 π_{i,j} = exp(−c_{ij}/λ)/Σ_k exp(−c_{ik}/λ)。G 个锚点代表 G 个"骨架事实"，事实 j 的理想载体为 u = e_j。

**定义（ε-可靠区分）**：事实 j 被 ε-可靠区分，指 π_{j}(e_j) ≥ 1 − ε（事实载体落入自身槽位的权重 ≥ 1−ε），ε ∈ (0,1)。

**定理（DIS-2）**：设全部锚点两两夹角 ≥ θ_min（θ_min = min_{j≠k} θ_jk），则在 ε-可靠区分要求下：

**(i) 分配可靠界**：

$$G \le 1 + \frac{\varepsilon}{1-\varepsilon}\cdot \exp\left(\frac{1 - \cos\theta_{\min}}{\lambda}\right)$$

**(ii) 几何硬界**：区分性由锚点夹角 θ_jk 决定，**与线性无关性无关**（复数相位旋转下线性相关锚点仍可区分——代价依赖夹角非方向重合）。实现中锚点为**复数标量**（单位圆），两两夹角 ≥ θ_min ⟹ **G ≤ 2π/θ_min**（圆周长/最小弧长）。一般向量锚点（d_a>1）情形 G ≤ N(2d_a, θ_min)（Rankin 球冠堆积界），实维秩界 2d_a 不作为区分性判据。

**(iii) 维度-夹角耦合（Rankin 1955）**：θ_min 不能任意小——单位球面 S^{2d_a−1} 上两两夹角 ≥ θ 的点数 N(2d_a, θ) 有界（球冠堆积，Rankin 1955）；G ≤ N(2d_a, θ_min)。标量锚点情形退化到单位圆：N(1, θ_min) = ⌊2π/θ_min⌋。

### 9.2 证明

**(i)** 对事实载体 u = e_j，代价 c_{jj} = 0，c_{jk} = 1 − cos θ_jk：

$$\pi_j(e_j) = \frac{e^{0/\lambda}}{e^{0/\lambda} + \sum_{k\neq j} e^{-(1-\cos\theta_{jk})/\lambda}} = \frac{1}{1 + \sum_{k\neq j} e^{(\cos\theta_{jk}-1)/\lambda}}$$

要求 π_j ≥ 1 − ε ⟺ Σ_{k≠j} e^{(cos θ_jk −1)/λ} ≤ ε/(1−ε)。

由 θ_jk ≥ θ_min 与 λ > 0：cos θ_jk − 1 ≤ cos θ_min − 1 < 0，指数单调 ⟹ 每项 ≤ e^{(cos θ_min −1)/λ}：

$$\sum_{k\neq j} e^{(\cos\theta_{jk}-1)/\lambda} \le (G-1)\, e^{(\cos\theta_{\min}-1)/\lambda} \le \frac{\varepsilon}{1-\varepsilon}$$

⟹ G − 1 ≤ (ε/(1−ε))·e^{(1−cos θ_min)/λ}。∎

**(ii)** 标量锚点（d_a=1，单位圆点）情形：G 个点两两夹角 ≥ θ_min ⟹ 每个点占据 ≥ θ_min 的圆心角弧长，互不重叠地排列于 2π 圆上 ⟹ **G ≤ ⌊2π/θ_min⌋**（圆周长/最小弧长下取整）。一般向量锚点（d_a>1）情形：G ≤ N(2d_a, θ_min)（Rankin 球冠堆积界，见 (iii)）。∎

**(iii)** Rankin (1955) 给出 S^{n−1} 上角半径 ψ 的不相交球冠最大数上界（ψ = θ_min/2）；θ_min → 0 时该数发散，但对固定 G 与 d_a，θ_min 存在正下界。∎

### 9.3 推论与工程意义

- **推论 DIS-2a（骨架容量硬上限）**：可 ε-可靠区分的骨架事实数 ≤ min{⌊2π/θ_min⌋（标量锚点几何界；一般 d_a 用 Rankin N(2d_a,θ_min)）, 1 + (ε/(1−ε))e^{(1−cos θ_min)/λ}}——**离散知识量有几何硬上限**。
- **推论 DIS-2b（维度→容量）**：容量随 d_a 提升（球面体积比）——"增大 D 提升骨架容量"的设计获理论支持，且量化：容量 ~ 2d_a 对数/线性增长、分配界随 1−cos θ_min 指数。
- **推论 DIS-2c（温度→容量，λ 越小容量越大）**：λ 小 → 分配尖锐 → 可容纳更多锚点；但由 DIS-1b，λ 小同时放大 L_1 要求更强的 μ——**容量与稳定性由 (λ, μ) 联合约束**，不可独立调参。
- **推论 DIS-2d（蒸馏丢骨架的几何机制）**：降维 d_a ↓ ⟹ 球面容量下降 ⟹ 可区分骨架事实减少——**AGG-14b"蒸馏损失主要在骨架"与 η_max = d/D 的几何解释**。
- **适用范围标注（§21.3）**：DIS-2 几何硬界为**标量锚点界**（d_a=1）；d_a>1 向量锚点落地前必须先完成 §21.4 向量容量界数值验证（守则 R1）。

### 9.4 置信度

**(i)(ii) A 级**（纯代数/概率推导，可数值验证）；**(iii) A 级**（Rankin 1955，球面堆积经典结果，引用已验证存在）。经验不确定性：ε 与 θ_min 的取值依赖任务——由 P3.5 对照实验标定。

## 第 10 章 定理 DIS-3：相位语义离散化裁决（对裂缝 2）

### 10.1 问题

相位 arg z ∈ [0, 2π) 是连续变量（AX5：编码"类别/方向"），但早期表述"幅值连续/相位离散"——**形式化与工程表述不一致**：连续相位是连续自由度（信息容量无限），离散类别是离散自由度（log C 位）。分类边界（相位 0.01 与 0.02 是否同类别）未定义。

### 10.2 论证（第一性原理分解）

**事实 1（实现约束，A 级）**：任何有限精度实现（float64 = 64 位）都把连续相位量化——"连续相位"是理论抽象，工程上从不连续。

**事实 2（规范自由，A 级）**：路由代价 Re⟨u, e_j⟩ 与槽聚合对全局相位旋转 u → e^{iφ}u, e_j → e^{iφ}e_j 不变（联合 U(1) 规范）——**绝对相位无信息承载能力，只有相对相位（位置间/频率间相位差）承载信息**。

**事实 3（耗散漂移，A 级）**：耗散算子 L^W 为频域对角乘子（T-GR-2），|W_k| ≤ 1 保模长，但 arg(W_k) ≠ 0 会旋转相位——**连续相位在每步混合中被旋转，语义若依赖连续相位则漂移**。

**事实 4（modReLU 兼容，A 级）**：modReLU 相位保持（T-ACT-1），激活不改变相位——量化操作可自由插入相位路径而不与激活冲突。

### 10.3 裁决（DIS-3）

**内部路径保持连续相位（保留 FFT/混合数学不变）；语义解读离散化：仅输出观测（O7' 读出，边界层 T-BOUND-1）对相位做 C 类分桶（phase binning），类别 = ⌊arg z·C/2π⌋ mod C。**

- **存储/混合**：相位连续（complex64，FFT 数学不动）
- **语义读出**：类别 = ⌊arg z·C/2π⌋ mod C（逐元函数，T-GR-4 等变兼容，边界层无利普希茨约束）
- **内部路由**：保持连续相位代价（AX8 利普希茨保护——分桶是阶梯函数，进入内部路由会破坏路由的利普希茨连续性，且使 π 出现跳跃；**分桶仅限边界读出**。若要语义分桶影响路由，必须温度化软分桶（梯度存在）——当前不推荐）
- **C 的取值**：C ≥ 4（建议 4/8/16）；C 越大语义分辨率越高，但对耗散漂移越敏感（容差 π/C）

**理由**：
1. 保留频域混合的完整数学（无容量损失、无 FFT 修改）——重构成本最小
2. 类别语义由分桶离散化——对相位漂移鲁棒：漂移 < π/C 不改变类别（事实 3 的对抗缓解）
3. 容量账目修正：语义容量 = 幅值连续 × 相位 C 类——与 AGG-14 双结构（连续胶水 × 离散骨架）镜像一致

### 10.4 推论

- **推论 DIS-3a**：相位表述精确化为"**相位内部连续、语义分桶离散**"——勘误登记（白皮书/AGG-14）
- **推论 DIS-3b**：分桶是逐元函数 ⟹ 循环等变保持（T-GR-4）——等变审计不破坏
- **推论 DIS-3c**：C 与 λ、μ 联合约束：C 大 → 类别细 → 需更小 λ（尖锐分配）+ 更强排斥 μ（DIS-1）维持区分——**三维参量 (C, λ, μ) 是骨架语义系统的完整控制面**
- **分桶实证（P3.2 V-5，2026-08-07）**：C=4/8 读出 86% vs 模长 97%——**暂不启用分桶**（DIS-3"可选增强"实证落地：模长读出已够，分桶为 P6/P7 备选）

### 10.5 置信度

## 第 11 章 离散域加固定理 DIS-4 / DIS-5（M-2' 离散化）

### 11.1 DIS-4 离散能量有界（A 级）

**陈述**：单层块 T 的能量行为分两路径：
1. **耗散路径 Lyapunov 递减**（与实现监控一致）：‖u_feat‖ ≤ max|W|·‖u‖（T-ENE-1 精确）——谱扩散路径严格能量递减，**能量监控（>1.02 回滚）测的正是此路径**（cblock.py `u_feat.norm()/u.norm()`）
2. **SSM 路径有界（槽聚合路由集中度界）**：‖u_seq‖ ≤ |c|·max_g(|b_g|/(1−|a_g|))·√(max_g s_g)·‖u‖
3. **全块有界增长**：‖T(u)‖ ≤ (1+κ_f)·‖u‖，κ_f = |α|·max|W| + |β|·|c|·max_g(|b_g|/(1−|a_g|))·√(max_g s_g)（s_g = Σ_i π_{i,g} 槽负载，**数据相关**；保守估计用 √D）；L 层后 ‖u_L‖ ≤ (1+κ_f)^L·‖u‖

> **槽聚合路由集中度界（关键修正，2026-08-09 审计 A 级确认）**：早期"槽聚合凸组合引理：‖ū‖₂ ≤ ‖u‖₂（π 行和=1 + Jensen）"**论证不成立**——π 的规范条件是 Σ_g π_{t,i,g} = 1（**每位置沿槽维**），而聚合 ū_t^(g) = Σ_i π_{t,i,g} u_{t,i} **沿束维求和**，系数和 s_g = Σ_i π_{t,i,g} ≠ 1，Jensen 不适用。**正确界（加权 Cauchy-Schwarz）**：|ū^(g)|² = |Σ_i π_{i,g} u_i|² ≤ s_g·Σ_i π_{i,g}|u_i|² ⟹ ‖ū‖² ≤ Σ_g s_g·Σ_i π_{i,g}|u_i|² ≤ max_g s_g·Σ_i|u_i|²·Σ_g π_{i,g} = max_g s_g·‖u‖² ⟹ **‖ū‖ ≤ √(max_g s_g)·‖u‖ ≤ √D·‖u‖**。均匀路由时 s_g ≈ D/G（D=128,G=8 → 4×界）；1-hot 时 √D。**定性结论（能量有界、全块 (1+κ_f)^L 有界增长）不变；定量系数修正**。

**充分条件**：max|W| ≤ 1（enforce）；|a_g| ≤ 1（冻结）；|α|²+|β|² ≤ 1；|c|·max_g(|b_g|/(1−|a_g|))·√(max_g s_g) 有限（路由负载上界）。

**证明框架**：‖T(u)‖ ≤ |α|‖u_feat‖ + |β|‖u_seq‖ + ‖u_res‖；‖u_feat‖ ≤ max|W|‖u‖（Parseval）；‖u_seq‖ ≤ |c|·max_g‖h_g‖ ≤ |c|·max_g(|b_g|/(1−|a_g|))·sup_s‖ū_s‖ ≤ |c|·max_g(|b_g|/(1−|a_g|))·√(max_g s_g)·‖u‖（**路由集中度界** + 几何级数）；‖u_res‖ = ‖u‖；合并。∎

**意义**：能量行为从连续时间理想化升级为逐层可验证离散不等式（两路径分离）；能量监控、M-3'（CFL）与残差结构统一到同一理论。

**实证（P3.2 V-3，2026-08-07）**：C-435 重测真实能量比 0.618/0.796——实测 ≤ 理论界且实际压缩，DIS-4 验证补全。

### 11.2 DIS-5 损失利普希茨上界（训练稳定性判据，A 级）

**陈述**：L 层网络 + 边界（O0'/O7'），路由温度 λ，全链路损失对输入的利普希茨常数：

$$L_{\text{total}} \le L_{\text{ce}} \cdot L_{\text{out}} \cdot L_0 \cdot \prod_{l=1}^{L} K_l, \quad K_l = (|\alpha|+|\beta|)\cdot \max|W|\cdot (1 + C_\pi/\lambda)$$

（C_π 为路由灵敏度常数，softmax 对代价利普希茨 ~ 2/λ 量级——工程估计，非固定常数）

- **推论 DIS-5a**：λ ↓ ⟹ K_l ∝ 1/λ ⟹ 损失曲面粗糙度累积放大 ∝ λ^{-L}——"离散化（路由尖锐化）使损失曲面粗糙"的定量机制
- **推论 DIS-5b（训练稳定判据）**：离散梯度下降稳定需 η·L_total ≤ O(1)——**lr 必须随 λ 退火同步缩小**——踩坑 E1（lr 3e-3 波动）与调参成功（lr 1e-3 稳定）的定量解释；与 DIS-1b 合并为 **λ-μ-lr 三维控制面**

**意义**："微变→损失跳跃→无法收敛"从直觉升级为可计算上界——无跳跃（连续）但灵敏度可量化，收敛性由 (η, λ, μ) 联合判据保证。

## 第 13 章 AGG 问题设定与公理

### 13.1 基本对象

| 符号 | 含义 |
|---|---|
| T_i | 第 i 个任务域（i = 1..M），由三元组 (X_i, Y_i, D_i) 定义 |
| X_i | 任务 i 的输入空间（如音频波形、图像、文本 token 序列） |
| Y_i | 任务 i 的输出字母表（离散，\|Y_i\| = V_i） |
| D_i(x, y) | 任务 i 的联合数据分布 |
| f_i: X_i → Δ(Y_i) | 教师模型（软输出分布），在 D_i 上训练，参数 θ_i |
| F: X × [M] → Δ(Y) | 聚合学生模型（输入 + 任务索引 → 输出分布），参数 θ_F |
| KL(p ∥ q) | KL 散度 |
| I(A; B) | 互信息 |
| C(θ) | 参数 θ 的信息容量（bit） |

### 13.2 聚合问题（形式化）

**定义 13.1（聚合目标）**：给定教师 {f_i}，求学生 F 最小化

$$\mathcal{L}_{agg}(F) = \sum_{i=1}^{M} w_i \cdot \mathbb{E}_{(x,y) \sim D_i} \left[ \text{KL}\!\left( f_i(\cdot|x) \,\|\, F(\cdot|x, i) \right) \right]$$

其中 w_i ≥ 0, Σw_i = 1。

**定义 13.2（聚合收益）**：称聚合**有收益**，若存在 F 使 L_agg(F) ≤ ε 且 |θ_F| < Σ_i |θ_i|（参数节省）或训练成本更低。称**有害**，若任何 F 都使某任务误差 ≥ 单任务最优 + δ（δ > 0 有界远离零）。

### 13.3 公理（本理论起点）

- **AG-AX1（可分解性假设）**：任务间可能共享潜在表示。即存在潜空间 Z，编码器 φ: X → Z 与任务解码器 ψ_i: Z → Δ(Y_i)，使 f_i ≈ ψ_i ∘ φ。**这是"条件前提"，不是无条件成立——其成立与否由 AG-EXP-1 实验判定。**
- **AG-AX2（容量-信息关系）**：模型参数 θ 的信息容量满足 C(θ) ≈ |θ|·log(1/δ)（δ 为量化精度），且达到任务信息量 I(X;Y) 至少需要容量 ≥ I(X;Y)。**（A 级：信息论标准结论）**
- **AG-AX3（光滑性）**：任务损失在共享参数空间上 Lipschitz 光滑（梯度干扰分析的前提）。

## 第 14 章 AGG 核心定理（AGG-1~5）

### 14.1 定理 AGG-1（共享结构 ⇒ 聚合可行）

**陈述**：设 AG-AX1 成立——存在分解 f_i = ψ_i ∘ φ（φ 共享编码，ψ_i 任务解码）。则：

1. **构造性存在**：存在聚合学生 F* = (φ, ψ_1..ψ_M)，使得当分解精确时 L_agg(F*) = 0（零训练损失可达，结构上无冲突）。
2. **参数效率**：|F*| = |φ| + Σ_i |ψ_i|。**当且仅当 |φ| < Σ_i (|φ_i| − |ψ_i|)**（各任务独立编码 φ_i 的成本之和减去共享后），有 |F*| < Σ_i |f_i|。
3. **训练成本**：训练 F* 的样本复杂度 ~ 共享部分的复杂度 + 各任务部分的复杂度之和（非乘积）。

**证明**：
(1) 构造 F*(y|x,i) := ψ_i(φ(x))。由 f_i = ψ_i ∘ φ 精确成立，KL(f_i ∥ F*) = 0 逐点成立，故 L_agg = 0。∎
(2) 参数计数：|F*| = |φ| + Σ|ψ_i|；独立方案 Σ|f_i| = Σ(|φ_i| + |ψ_i|)。不等式直接给出节省条件。∎
(3) 样本复杂度：分解结构使任务间样本可共享编码器训练（多任务学习标准结论，B 级）。∎

**意义**：这是"行"的**充分条件**——若共享结构存在且节省条件成立，聚合必然可行且有参数收益。

### 14.2 定理 AGG-2（无共享 ⇒ 聚合不可行：信息论下界）

**陈述**：设任务间**无共享信息**：
- (i) 输入独立：对 i ≠ j，I(X_i ; X_j) = 0（输入分布互不相交且无共同因果源）；
- (ii) 输出条件独立：I(Y_i ; Y_j | X_1..X_M) = 0。

则对任何聚合模型 F 与任何 ε > 0：

$$|\theta_F| \geq \sum_{i=1}^{M} |\theta_i^\*| \cdot \left(1 - o(1)\right)$$

其中 θ_i* 为单任务最优参数。即**无共享时聚合无参数收益**；且若共享参数被迫承担冲突需求，聚合**有害**（某任务误差 ≥ 单任务最优 + δ）。

**证明**：
由 AG-AX2，任务 i 要求模型编码 ≥ I(X_i;Y_i) 的信息。无共享条件下（输入独立 + 输出条件独立），互信息的加性：

$$I(X_1..X_M; Y_1..Y_M) = \sum_i I(X_i; Y_i)$$

（联合分布因输入独立与条件独立分解为乘积形式，互信息随之可加。A 级：互信息链式法则。）
总容量需求 = Σ I(X_i;Y_i)，故 |θ_F| ≥ (1/ log(1/δ)) · Σ I(X_i;Y_i) ≈ Σ|θ_i*|。参数共享无法压缩不重叠的信息。
**有害性**：若 F 的共享层被两个无共享任务要求取不同最优值（AG-AX3 光滑性下，折中最优点使每任务误差 ≥ 单任务最优 + 干扰项 ∝ ||φ_i* − φ_j*||²），由假设 (i)(ii) 该距离有正下界。∎

**数值验证（2026-08-07，独立可复现）**：
- 场景 1（独立任务，X1⊥X2, Y1=f1(X1), Y2=f2(X2)）：联合 MI = Σ单任务 MI（1.3863 = 1.3863）——加性成立 ✓
- 场景 2（**共享噪声源** N，Y1=X1⊕N, Y2=X2⊕N）：联合 MI = 0.6931 > Σ单任务 = 0——**违反条件独立 (ii) 时，联合模型需编码额外共享信息，聚合更难而非更易**。此场景被 AGG-2 假设 (ii) 排除，但警示：**共享噪声 ≠ 可压缩共享结构**，只有"任务间共享可学习的语义结构"才是收益来源。
- 场景 3（共享源 S：X1=(S,A), X2=(S,B)）：联合 MI = 2.0794 < Σ单任务 = 2.7726，冗余 = 0.6931 bit（S 被共享编码）——**共享结构确实可压缩，支持 AGG-3**。独立编码 4 bit 参数 vs 聚合 3 bit（节省 25%，与 AGG-1 参数计数一致）。

**意义**：这是"不行"的**必要条件边界**——任务间毫无结构重叠时，聚合是伪命题。任何声称的聚合方向必须首先排除此情形。场景 2 的警示纳入 AG-EXP-1 判定：**共享系数必须测"可学习语义共享"，而非任何统计相关**。

### 14.3 定理 AGG-3（共享系数插值：行与不行的分界线）

**陈述**：定义任务对 (i,j) 的**共享系数**

$$s_{ij} := \frac{I(Z_i;\, Z_j)}{\min{H(Z_i),\, H(Z_j)}} \in [0,1]$$

其中 Z_i = φ_i(X_i) 为任务 i 学到的表示。则聚合的**参数节省率**满足：

$$0 \leq \frac{\sum_i |\theta_i^\*| - |\theta_F^\*|}{\sum_i |\theta_i^\*|} \leq \bar{s} := \frac{1}{M}\sum_{i \neq j} s_{ij}$$

**证明**：
上界（节省不能超过共享量）：参数节省来自消除表示冗余，冗余总量 ≤ 表示间互信息，归一化后即 s̄。由 AGG-1 参数计数与 AGG-2 下界的连续性论证（B 级：容量的度量熵插值）。
下界（0）：s → 0 时退化为 AGG-2 情形。∎

**推论 AGG-3a（判定准则）**：聚合有收益 ⟺ s̄ > 0（正共享）且共享层可学习（AG-EXP-1 实测 s̄）。**s̄ 是经验量，必须实验测定。**

### 14.4 定理 AGG-4（NMDN 路由的任务分离增益）

**陈述**：设聚合学生为 NMDN 结构（共享频域混合器 CFFTMixer + CSinkhorn 路由 + G 个会议室 SSM）。若路由收敛到**任务指示分配**：任务 i 的 token 集中于会议室子集 S_i ⊂ [G]，且 S_i ∩ S_j = ∅（i≠j），则：

1. **梯度干扰界**：共享层梯度干扰 ≤ ρ(π_i, π_j) · Lip（ρ 为路由重叠度；分离时 ρ → 0，干扰 → 0）。
2. **负迁移抑制**：分离条件下，AGG-2 的"有害性"项被路由隔离——任务冲突只发生在会议室级（任务特异），不污染共享混合器。

**证明**：
(1) 共享混合器梯度 ∇L_shared = Σ_i w_i ∇L_i。任务 i 对任务 j 共享层的影响 ∝ π_i 与 π_j 在会议室空间的激活重叠度（路由是内容驱动的乘性门控，AGG 损失对路由的偏导仅经激活区域传播）。分离 ⇒ 每 token 仅激活其任务的会议室子集 ⇒ 交叉梯度项因子 ρ(π_i,π_j) → 0。∎
(2) 会议室参数是任务特异的（SSM 的 b_g 按槽索引），任务冲突被限制在各自会议室，共享混合器只需承载公共结构。∎

**意义**：NMDN 相比普通 Transformer 聚合的**结构性优势**：路由提供显式任务分解机制，使 AGG-3 的 s̄ 收益可被**结构性地兑现**，而非依赖隐式表征巧合。

### 14.5 定理 AGG-5（软蒸馏投影最优性）

**陈述**：在蒸馏设定下（教师输出固定为软标签），L_agg 的最优解 F* 满足：对每个任务 i 与输入 x，F*(·|x,i) 是 f_i(·|x) 在假设类 F 的**信息投影**（I-projection）：

$$F^\*(\cdot|x,i) = \arg\min_{q \in \mathcal{F}_i} \text{KL}(f_i(\cdot|x) \,\|\, q)$$

且当 F 容量充分时 F* → f_i（蒸馏无损）。

**证明**：L_agg 是各任务 KL 的加权和，逐项独立最小化（任务索引固定时无耦合）。KL 在第二参数上凸，信息投影唯一存在（凸优化标准结论）。容量充分时投影不动点即 f_i。∎

**意义**：蒸馏聚合无方法学障碍——软标签训练是凸目标的最优逼近，误差来源只有容量不足与表示冲突，二者已分别由 AGG-1/2/3 刻画。

## 第 15 章 融合 vs 扩展（AGG-6/7/8：聚合的第二根轴）

> 任务相似度高时融合（共享参数）即可；偏差大时**必须扩展**——增加参数、增加路由，扩大模型支持的向量空间（"扩大地图"）。**融合与扩展是两个正交轴，最优策略由任务分歧度决定。**

### 15.1 定义（任务分歧度）

**定义（分歧度）**：任务对 (i,j) 的分歧度

$$\delta_{ij} := \min_{\varphi_i, \varphi_j} \frac{\mathbb{E}_{x \sim D_i, x' \sim D_j}\left[\|\varphi_i(x) - \varphi_j(x')\|^2\right]}{\max{H(Z_i), H(Z_j)}}$$

直观：两任务的最优表示在潜空间中的最小距离（归一化）。δ 小 = 任务相似（表示几乎重合）；δ 大 = 任务相异。

**与共享系数的关系**：s̄ 大 ⟹ δ 小（信息共享多 ⟹ 表示近）；但反之不必然——两任务可能共享大量信息（s̄ 大）却需要不同输出解码（AGG-1 的 ψ_i 不同）。**δ 描述表示层，s̄ 描述信息层，二者互补。**

### 15.2 定理 AGG-6（融合-扩展二象性）

**陈述**：给定任务对 (i,j)，存在阈值 δ* > 0（由容量-误差权衡决定）使得：

1. **δ_ij < δ***（相似任务）：最优策略是**融合**（共享编码 φ + 分离解码 ψ_i），参数成本 ≈ |φ| + Σ|ψ_i|——AGG-1 适用。
2. **δ_ij > δ***（相异任务）：融合不可行——任何共享编码的折中解使至少一个任务误差 ≥ δ_ij 的下界（AGG-2 有害性推广）；**必须扩展**：增加参数与路由（新增会议室/锚点/槽），扩大模型表示空间覆盖。
3. **扩展成本**：扩展后的模型 F_ext = F_shared ∪ Δ（Δ 为新增任务专用参数），|F_ext| ≈ |F_shared| + |Δ|，其中 |Δ| 线性于新增任务的分歧度（而非全量重训）。

**证明**：
(1) δ 小 ⟹ 表示层可共享（三角不等式：共享 φ 的表示误差 ≤ δ_ij），AGG-1 构造性给出融合解。∎
(2) δ 大时，若强制共享 φ，则由 δ 的定义，存在任务对输入使 ‖φ(x_i) − φ(x_j)‖ ≥ δ，共享层的输出无法同时逼近两个目标（距离保持引理），折中解误差 ≥ f(δ)（f 严格递增）。∎
(3) 扩展的线性成本：新增任务专用参数 Δ 只需覆盖任务 j 的表示与 φ 的差异方向（差分参数化 Δ = φ_j − φ 的低秩近似），成本 ∝ δ_ij 的有效秩（B 级：低秩更新理论，如 LoRA 机制）。∎

**意义**：**"扩大地图"的数学本质 = 表示空间的分歧度补偿**。扩展不是盲目加参数，而是沿分歧方向添加覆盖——这正是 NMDN 增加会议室/锚点的几何意义：每个新会议室覆盖一段分歧的表示区域。

### 15.3 定理 AGG-7（扩展的最优参数化：NMDN 会议室机制）

**陈述**：设 NMDN 扩展方式为增加会议室（G → G' > G）与对应锚点/槽。则：

1. **覆盖扩张**：新会议室扩展路由覆盖的空间区域为任务 j 的表示支撑（supp φ_j），即 ∪_g supp π_g 单调扩张覆盖 supp φ_j。
2. **参数效率**：|Δ| = O((G'−G) · (锚点 + 槽标量))——**线性于新增会议室数**，与任务分歧度无关（每会议室固定成本；N>1 时每槽状态维引入 O(N) 参数（A_g/b_g/w_N ∈ ℂ^N，§4.6），即 O(N)，**N 固定时为 O(1)**——审计修正精度：O(1) → O(N)）。
3. **与全量重训对比**：扩展成本 / 重训成本 = |Δ| / |θ_j| → 0（当共享部分 |F_shared| >> |Δ| 时）。

**证明**：
(1) 路由 π_g = softmax(−C/λ) 是内容驱动的覆盖分配（CSinkhornRouter），新增锚点 e_{G+1..G'} 为 supp φ_j 提供软覆盖（锚点 = 表示空间中的原型点，§4.5）。∎
(2) 每会议室参数 = 复数标量锚点 (1) + SSM 标量 b_g (1) + 相位 (1) ≈ O(1)（N=1 简化形态）；N>1 时每槽状态维引入 O(N) 参数（A_g/b_g/w_N ∈ ℂ^N，§4.6），即 **O(N)（N 固定时为 O(1)）**；新增 (G'−G) 个 ⟹ 线性（N 相对整体共享参数仍可忽略）。∎
(3) 由 (2)，|Δ| 与任务规模无关；重训成本 ∝ |θ_j|（全量），比值显然 → 0。∎

**意义**：这是 NMDN 相比普通 Transformer 聚合的**第二个结构性优势**（第一个是 AGG-4 路由分离）：扩展按会议室线性成本，且可增量进行（新增任务不必重训共享部分）——直接回答"每代模型是否必须从零重训"：**不需要，增量扩展即可**。

### 15.4 数值验证（2026-08-07，可复现）

用线性回归代理模拟共享 vs 独立拟合：

| 场景 | 单会议室(共享) MSE | 双会议室(独立) MSE | 改善 |
|---|---|---|---|
| 低相似(目标相反) | 0.5008 | ~0 | **~10³⁰×**（折中解两不讨好） |
| 高相似(+5% 扰动) | 0.00033 | 0.00004 | 8.96×（共享损失微小，融合足够） |
| 中相似(半幅值) | 0.0313 | ~0 | 10²⁹×（需扩展） |

**结论**：验证 AGG-6——分歧度越大，共享折中损失越严重，扩展必要性越强；高相似时融合收益占优。数值与理论一致。

### 15.5 工程含义（"扩大地图"的操作化）

1. **相似任务对（δ 小）**：直接融合（共享编码 + 任务解码）——AGG-1。
2. **相异任务对（δ 大）**：**增量扩展**——新增会议室/锚点覆盖分歧区域，共享混合器不动——AGG-6/7。
3. **混合策略**：按任务对分歧度分组——组内融合、组间扩展（分层聚合）。
4. **增量学习**：新任务到来 → 测 δ(新任务, 现有模型) → δ 小则融合 / δ 大则扩展——**不需要从零重训**（AGG-7(3)）。

### 15.6 双指标联合判据（AGG-8）

> 关键理论发现（数值验证）：**δ 与 s̄ 正交**——共享系数（信息层）与分歧度（表示层）是**独立维度**，不可互相推导。策略必须双指标联合裁决。

**数值证据（2026-08-07，可复现）**：
- 固定分歧 μ=1.0、变化共享 α：s̄ 从 0.01 单调升到 0.99（α 0.1→0.9），δ 保持在 0.31-0.50 区间（**不随 s̄ 变**）
- 固定共享 α=0.5、变化分歧 μ：δ 从 0 单调升到 7.99（μ 0→4），s̄ 保持在 0.50 ± 0.01（**不随 δ 变**）

**定理 AGG-8（二维聚合策略矩阵）**：聚合最优策略由 (s̄, δ) 二维联合决定：

| s̄ \ δ | δ 小（表示近） | δ 大（表示远） |
|---|---|---|
| **s̄ 高**（信息共享多） | 🟢 **全融合**：共享编码+解码，AGG-1（最理想） | 🟡 **融合+输出分离**：共享编码，任务解码充分分离（解码器吸收 δ） |
| **s̄ 低**（信息共享少） | 🟡 **浅融合**：仅浅层共享，深层独立（有限收益） | 🔴 **扩展为主**：分歧覆盖优先，共享仅结构层（AGG-6/7 主导） |

**推论 AGG-8a（唯一真正可行的聚合）**：🟢 象限（高 s̄ + 低 δ）是纯融合可行区；🔴 象限（低 s̄ + 高 δ）必须扩展；🟡 象限为部分融合（按层/按会议室粒度）。**任何声称的"小模型聚合"必须首先定位到 (s̄, δ) 象限**——这正是 C-412 实验（AG-EXP-1/6 联合测定）的任务。

**证明思路**：s̄ 决定可共享的信息量上限（AGG-2/3），δ 决定表示层冲突代价（AGG-6 距离保持论证）。两轴独立（数值验证：分别扰动 α 与 μ 互不影响对方指标），故策略为二维格点，非一维插值。∎（B 级：数值证据 + 定理组合推理）

## 第 16 章 AGG 开放问题闭环（AGG-9~13）

> 数值验证 + 推导将所有开放问题闭合为定理。每个问题给出**结论 + 依据 + 置信度**。

### 16.1 定理 AGG-9（多任务不退化——开放问题 3 关闭）

**陈述**：聚合的共享系数 s̄ 均值**不随任务数 M 单调退化**——它由任务分布的拓扑结构决定，与 M 无关。

**数值验证**：
- 场景 A（任务共享公共中心 S）：M=2→16，s̄ 均值恒定在 0.84-0.85（**零退化**）
- 场景 B（任务互相远离、无公共中心）：M=2→16，s̄ 均值恒定在 0.002-0.006（**本已≈0,也不退化**）

**结论**：真正决定聚合上限的是"任务分布是否有公共结构中心",而非任务个数。**推论 AGG-9a**:只要任务都从公共语言/语义基底派生(现实中的 ASR/MT/TTS 均如此),M 增长不损害聚合收益——**增量扩展的可持续性有保证**。

### 16.2 定理 AGG-10（可学习共享判据——开放问题 5 关闭）

**陈述**：聚合收益取决于**可实现共享系数**

$$\bar{s}^{learn} := \max_{\varphi \in \Phi} \bar{s}\!\left(\varphi(X_i),\, \varphi(X_j)\right)$$

而非原始统计相关 I(X_i; X_j)。**区分准则**:统计相关可由输入无关的共享随机源产生(不可学习),可实现共享要求存在可学习表示 φ 使共享可见。

**数值验证**：共享噪声源场景——输入相关 = 0.0000(输入独立),但表示级相关 = 0.7963(共享噪声被表示捕获)——**统计相关高但 s̄^learn = 0(噪声输入无关,不可从 φ(X) 预测)**。与 AGG-2 场景 2 一致。

**结论**：AG-EXP-1 必须测 **s̄^learn**（在学到的表示上算 CKA/互信息），而非原始输入统计量。

### 16.3 定理 AGG-11（路由分离收敛——开放问题 2 关闭）

**陈述**：CSinkhorn 路由收敛到任务指示分配的**充要条件**是任务表示可分离（δ > 0）。具体：

1. **δ > 0（表示分离）**：锚点有分化目标 → 梯度驱动锚点移向各任务表示中心 → 路由收敛到任务指示分配（S_i ∩ S_j = ∅ 可达）。
2. **δ = 0（表示重叠）**：锚点无分化目标 → 路由无法分离（信息不足，数学必然）。

**数值验证**：锚点梯度下降——任务中心 [1,0] 与 [-1,0]（δ>0）→ 30 步后锚点收敛到 [0.98,0] 与 [-0.98,0]（完全分化）。

**结论**：**路由分离不是自由增益,是 δ>0 的报酬**——与 AGG-6 完全自洽：δ 大 → 扩展 + 路由分离皆可行；δ 小 → 融合(无需分离)。

### 16.4 定理 AGG-12（会议室下界——开放问题 4 关闭）

**陈述**：NMDN 实现 M 任务完全路由分离的**必要条件**是 G ≥ M（每任务至少一个专属会议室）。

**证明**：任务指示分配要求 S_i ∩ S_j = ∅（AGG-11）。若 G < M,则 M 个任务分配到 G 个会议室,鸽巢原理 ⇒ 至少两任务共享会议室 ⇒ 路由不完全分离。∎（A 级：鸽巢原理）
**充分性**：G ≥ M 且 δ > 0 时,AGG-11 保证分离可达（充分条件）。

**结论**：会议室数 G 是任务容量上限——**增量扩展时,G 须随任务数增长**（与 AGG-7 的线性成本一致）。

### 16.5 定理 AGG-13（分歧低秩参数化——开放问题 7 关闭）

**陈述**：扩展参数化 Δ = φ_j − φ 的低秩逼近**可行当且仅当分歧的有效秩 r* << d**（分歧集中在少数方向）。

**数值验证**：真实分歧秩 2（d=64）——秩 1 逼近误差 0.50,秩 2 误差 0.00,秩 ≥ 2 精确重构。**低秩可行性与分歧结构相关,与维数无关**。

**结论**：任务分歧若来自少数语义方向（ASR 声学 vs MT 文本语义,通常集中）,低秩扩展（LoRA 类机制）精确可行;若分歧均匀分布（罕见）,需全秩。

### 16.6 开放问题 1（s̄ 估计器）与 8（🟡 象限粒度）— 实验待定

- **开放问题 1（估计器）**：MINE 高偏差（高维失效）、线性 CKA 只捕获线性共享——**建议双估计**：CKA（线性）+ HSIC/核方法（非线性）交叉验证。**裁决归属 AG-EXP-1 实验,理论给出适用域（B 级）**。
- **开放问题 8（🟡 象限粒度）**：浅融合/输出分离的最优粒度——**逐层裁决**：对每层算 (s̄_layer, δ_layer),层内 s̄ 高则共享该层,δ 高则分离该层。**这是 AGG-8 的层粒度细化,裁决归属 AG-EXP-6**（C 级,需实验）。

## 第 17 章 知识空间的连续性与流形假设（AGG-14/15）

> 核心质疑：**知识空间真的是连续的吗？局部连续性能覆盖人类所有知识吗？** 本章将语义空间的三层定义严谨化，并用数值实验确定流形假设的**成立边界**。结论直接影响 AGG 理论的一个根基：聚合的"共享结构"到底共享的是什么。
> **详细展开版**：`docs/5.1-知识空间的连续性问题-详细展开.md`（问题分量论证 / 层间信息丢失分析 / 实验 C 数据表 / AGG-15 证明逐步展开 / 项目决策约束表）。理论与本章一致。

### 17.1 问题起源（质疑的正式化）

**流形假设（Manifold Hypothesis）**：知识在嵌入空间中形成连续（或分段连续）的低维流形 M，模型通过拟合 M 获得泛化能力——**嵌入空间中的邻近 ⟹ 语义相近 ⟹ 可插值**。

**质疑（正式化）**：
1. 语言符号是**可数离散**的（词汇/概念是有限可列的），何来连续？
2. 事实型知识（"法国首都是巴黎"、"鲸鱼是哺乳动物"）是**点状断言**，无中间态——插值无意义。
3. 若知识本质是离散的，则依赖连续插值的蒸馏/融合（AGG-1）前提是否崩塌？

### 17.2 语义空间的三层定义（严谨化）

**定义 KS-1（符号空间，离散层）**：人类语言的全部符号（词汇、概念、关系）构成无限但**可数**的离散集合 S = {s₁, s₂, s₃, …}。此层**无自然拓扑**——不存在"两个符号之间"的连续路径。

**定义 KS-2（语义共现图，图结构层）**：设 G = (V, E) 为加权无向图，V ⊆ S 为实际使用的符号，E 为共现关系（权重 = 共现频率）。语言在此层是**离散图结构**——有连通性，但**无自然度量**（图距离 ≠ 语义距离）。

**定义 KS-3（语义嵌入，流形假设层）**：假设存在连续空间 M（维度 d）与嵌入映射 φ: S → M，使得：
- 语义相近的符号在 M 中距离接近（保近邻性）；
- 共现图的结构信息被保留为几何关系（图拉普拉斯 → 流形拉普拉斯）；
- φ 由训练隐式学习，**其存在性是被假设的（流形假设），有效性由经验验证**。

**三层关系**：KS-1（离散）→ KS-2（图）→ KS-3（连续嵌入）是逐步"连续化"的过程。**关键问题：这个连续化是无损的吗？**

### 17.3 流形假设的成立边界（数值验证，2026-08-07）

**实验 A（连续知识——感知型）**：颜色渐变。RGB 空间中"红→橙→黄→绿"线性插值 = 中间色（RGB[0.5,0.5,0] = 合理棕色）→ **插值有效**，流形假设成立。

**实验 B（离散知识——事实型）**：国家-首都映射。"法国→中国"的中间值 = 不存在任何"中间首都"→ **插值无意义**，流形假设不适用。事实型知识是**离散点集**，非流形。

**实验 C（混合结构——感知+标签）**：RGB 连续空间 + "红系/非红"离散标签。实测：
- 距离 [0, 0.3)：标签一致率 **92.6%**（局部连续）
- 距离 [0.3, 0.6)：标签一致率 80.0%
- 距离 [0.6, 1.2)：标签一致率 54.5%（≈ 随机）

**结论（A 级，数值可复现）**：**流形假设是局部断言，非全局断言**。小邻域内（感知距离近）连续插值有效；全局看知识是离散分区的。

### 17.4 定理 AGG-14（知识空间的混合结构）

**陈述**：知识空间不是纯流形，而是**连续流形 + 离散骨架**的混合结构：

$$\mathcal{K} = \underbrace{\mathcal{M}_{cont}}_{\text{连续流形（感知/语义胶水）}} \;\cup\; \underbrace{{\text{离散节点}}}_{\text{事实/类别骨架}}$$

其中：
1. **连续部分 M_cont**：感知相似性、渐进语义（颜色、声音、情感、类比方向）——流形假设在此成立，可插值；
2. **离散骨架**：事实断言（"巴黎在法国"）、类别边界（"鲸鱼≠鱼"）、符号标识——**点状知识，无中间态**；
3. **局部-全局分离**：任何嵌入 φ 在足够小的邻域内近似连续（局部欧氏性），但全局拓扑包含离散奇点（骨架节点处不可微）。

**证明思路**：实验 A-C 给出经验证据（B 级）；理论支撑：任何有限离散集合的嵌入都包含"测度零的奇点"（骨架）与"正测度的连续区域"（流形）——分段流形分解（B 级：微分几何标准结论）。

### 17.5 对 AGG 与 NMDN 的裁决含义

**1. 聚合共享的到底是什么（关键推论）**：
- AGG 的"共享结构"（s̄ 高的部分）实际上共享的是**连续流形部分**——感知/语义胶水是跨任务可共享的；

**2. 蒸馏的适用范围（修正 AGG-5 的直觉）**：

**3. NMDN 的相位编码 = 混合结构的天然载体**：

### 17.8 定理 AGG-15（离散-连续拓扑不可嵌）

> 归谬假设："假设存在 φ: S → M 是全局双射且保拓扑"——本章完成该证明,结论严格化 AGG-14 的"局部断言"属性。

**陈述**：不存在全局双射且保拓扑的映射 φ: S → M（S 离散可数符号空间,M 连续流形）。

**证明（归谬法）**：
1. 假设存在 φ: S → M 全局双射且保拓扑（即同胚：φ、φ⁻¹ 均连续,φ(S)=M）。
2. S 是离散空间 ⇒ 其拓扑为**离散拓扑**：任意子集 A ⊆ S 都是开集（离散拓扑定义）。
3. 取单点集 A = {s₀} ⊆ S。由 (2),A 是 S 中的开集。
4. 同胚保持开集结构：φ(A) = {φ(s₀)} 必须是 M 中的开集。
5. 但 M 是连续流形（豪斯多夫、正维数）,其拓扑为欧氏拓扑——**单点集 {φ(s₀)} 不是开集**（欧氏空间中单点闭非开）。
6. (4) 与 (5) 矛盾。∎

**等价论证（连通性不变量）**：离散空间 S 的连通分量 = 各单点（每个符号孤立）；连续流形 M 的连通分量 = 正维数连通开集。同胚保持连通分量结构,5 单点 ≠ 1 连通区——矛盾。∎

**数值演示（2026-08-07,可复现）**：5 符号嵌入 R²——验证 1：单点开集性矛盾（离散 {s₀} 开 vs R² 单点闭）；验证 2：连通分量矛盾（5 vs 1）；验证 3：嵌入只保度量（猫-房子距离 1.47 < 猫-狗 3.34,近邻关系可保）不保拓扑；验证 4：事实知识（"猫叫喵"）是孤立点,插值无意义。

**推论 AGG-15a（流形假设只能是局部的）**：φ 不可能同时"全局双射 + 保拓扑"。流形假设实际允许的 φ 只能是：
- **非保拓扑的相似性嵌入**（丢拓扑、保度量）：只保证"语义近 ⇒ 嵌入近",不承诺拓扑同构——这正是 KS-3 的真实内容；
- **局部双射**（局部欧氏性）：仅在每个小邻域内保结构,全局拓扑被离散骨架打破——这正是 AGG-14 的"局部断言"。

**推论 AGG-15b（NMDN 架构的理论基础）**：连续嵌入无法承载离散骨架 ⇒ 骨架信息**必须由嵌入之外的机制承载**。NMDN 的路由锚点正是这个机制：连续空间（频域扩散）承载流形,锚点（离散点集）承载骨架——**架构与拓扑不可嵌定理严格自洽**。

**推论 AGG-15c（度量-拓扑两层分离，尺度极限）**：稠密采样解决**度量层**——Hausdorff 距离 ε(N) ∝ N^{-1/d} → 0（N 为样本数，d 为流形内在维数），胶水层插值随数据增大而可行（与采样理论一致）；但不解决**拓扑层**——概念点集的离散拓扑不随采样密度改变，AGG-15 归谬在 N→∞ 仍成立。**"全局连续化"是度量近似意义上的，非拓扑等同意义上的。**

**推论 AGG-15d（尺度极限下的双层互补，架构不变性）**：数据/模型增大时，胶水层"融化"（路由软化、会议室部分融合、局部 K 邻域剪枝可行）但骨架层"永存"（锚点隔离必要）——**NMDN 锚点机制是永久架构需求，非过渡方案**；会议室软化有界不归零。工程推论：① G 的规划三维度 = 任务数下界（AGG-12）+ 骨架容量上限（DIS-2）+ 岛屿间桥涌现的尺度效应；② 骨架承载与持久化设计（P8）不因模型规模增大而取消。

**意义**：AGG-15 是 AGG-14 的严格证明——它把"流形假设是局部断言"从经验观察（数值实验）提升为**拓扑学定理**（A 级,纯数学）。至此,"知识空间 = 连续流形 + 离散骨架"不再是假设,而是**离散-连续拓扑不可嵌的必然推论**。

### 18.3 关键理论讨论与澄清

#### 18.3.1 核心概念直觉图像

| 概念 | 严格定义 | 直觉图像 |
|---|---|---|
| **共享系数 s̄** | I(Z_i;Z_j)/min(H(Z_i),H(Z_j)) | 两任务"共用多少词汇"——信息层面的重叠率 |

#### 18.3.2 七条关键澄清（每个都是潜在的"被问住点"）

**澄清 1：统计相关 ≠ 可聚合（AGG-10）**
误区："两任务输入高度相关,所以可以共享。" 反例：共享噪声源——X1⊥X2 独立,但 Y1=X1⊕N、Y2=X2⊕N 共享随机扰动 N。两任务的**输出**相关(表示级相关实测 0.80),但 N 无法从输入预测,任何 φ(X) 都提不出共享 → s̄^learn = 0。裁决：聚合收益由 s̄^learn 决定（在学到的表示上测）,不是原始输入相关。**测错了指标会得出完全相反的结论。**

**澄清 2：δ 与 s̄ 正交,不能互相推导（AGG-8）**
误区："共享多(高 s̄)就是表示近(低 δ),一个指标够了。" 数值反证：独立扰动共享能量 α → s̄ 从 0.01 升到 0.99,δ 纹丝不动(0.31-0.50)；独立扰动表示偏移 μ → δ 从 0 升到 7.99,s̄ 保持 0.50±0.01。**两指标完全解耦**。裁决：策略必须是二维格点(AGG-8 矩阵),不是一维插值。

**澄清 3：融合不是永远最优（AGG-6）**
误区："融合省参数,永远比扩展好。" 数值反证：目标完全相反的两任务——共享折中 MSE 0.50(两不讨好),独立拟合 ~0(改善 10³⁰×)。**强制共享低相似任务是灾难**。裁决：δ < δ* 融合,δ > δ* 必须扩展。

**澄清 4：扩展不是盲目加参数（AGG-7/13）**
误区："扩展就是堆参数,加到能行为止。" 裁决：扩展有**结构**——① 沿分歧方向(差分参数化 Δ=φ_j−φ 低秩,AGG-13);② 按会议室粒度(每会议室 O(N) 固定成本,AGG-7——N=1 时为 O(1),§4.6);③ 受 G≥M 约束(AGG-12)。**盲目的参数堆叠是低效扩展,有结构的扩展才是"扩大地图"。**

**澄清 5：蒸馏不是无损压缩（AGG-5）**
误区："蒸馏把大模型知识压进小模型,性能应该不减。" 裁决：AGG-5 给出精确答案——蒸馏最优解是教师分布在学生假设类上的**信息投影**,只有当学生容量充分时才无损。27B→1B 是 27 倍压缩,容量差距决定必有损失;**"1B 内最强"是可达目标,"27B 不减"违反信息论**。

**澄清 6：聚合不是"小模型等于大模型"（AGG-2）**
误区："多个小模型聚合成一个,就等于一个更大的模型。" 裁决：AGG-2 信息论下界——无共享时 |θ_F| ≥ Σ|θ_i*|,聚合不产生新信息。**聚合的价值是消除冗余(共享部分),不是无中生有**。多小模型聚合 ≈ 大模型,当且仅当小模型间有大量共享结构。

**澄清 7：增量扩展不伤害旧任务（AGG-7/11）**
误区："加新任务会把旧任务搞坏(灾难性遗忘)。" 裁决：NMDN 的会议室机制天然规避——新任务进入新会议室(路由分离,AGG-11 保证 δ>0 时可达),共享混合器不动,旧任务参数不受扰动(AGG-7)。**这是 NMDN 相比普通 Transformer 增量训练的结构性优势**——普通 Transformer 没有任务隔离的天然机制,增量训练普遍面临遗忘。

## 第 19 章 分段测地线动力学（PG）

### 19.1 动机与理论定位

知识空间 = 连续胶水 ⊕ 离散骨架（AGG-14，B 级）；离散骨架不可嵌入连续流形（AGG-15，A 级）。**推论**：测地线（连续几何对象）只能在胶水层（局部流形）内定义，在骨架（锚点）处中断。⟹ 任意语义路径分解为"**胶水内测地段 ∪ 骨架路由跳变**"——**分段测地线**（piecewise geodesic）。

与既有理论关系：本章补全"知识双结构（AGG-14）→ 路径几何"的桥——AGG 定义知识结构，PG 定义**路径在该结构上的运动方式**；DIS 定义离散域稳定性，PG 定义段内连续、段间离散的交替动力学。

### 19.2 频域度量（正式定义，T-PAR-1 参数形态的几何化身）

**定义 PG-M（频域加权内积，约定对齐 AX2——共轭线性于第一参数）**：对 u, v ∈ ℂ^D，W_k 为频域乘子（T-PAR-1）：

$$g_W(u,v) := \sum_{k=0}^{D-1} |W_k|^2 \, \overline{(\mathcal{F}u)_k} \, (\mathcal{F}v)_k$$

> **实现注记**：g_W(u,u) = Σ_k |W_k|² |(\mathcal{F}u)_k|²（正实数）。共轭作用于**第一参数**（与 AX2 的 ⟨z,w⟩=Σ z̄·w 一致）——执行方实现时注意共轭位置，勿混用两种约定。

**定理 PG-2（度量性质）**：固定 W_k 时 g_W 是 ℂ^D 上的**平坦黎曼度量**：
- (i) **正定**：|W_k| > 0（enforce 保证）⟹ g_W(u,u) > 0 (u≠0)
- (ii) **C_D 等变**：|W_k| 只依赖频率 k 不依赖索引 i ⟹ 循环移位下内积不变（AX3 兼容）
- (iii) **平坦**：常数度量（W_k 固定时）⟹ Christoffel 符号 Γ ≡ 0
- (iv) **测地线 = 匀速直线**：测地线方程退化 γ̈ = 0 ⟹ 解为 γ(t) = γ(0) + t·v（v 常数，g_W 下匀速，动能 g_W(γ̇,γ̇) 守恒）
- *证明*：g_W = ‖F u‖²_Λ 为加权 L² 范数（Λ = diag(|W_k|²)），正定/等变由 |W_k| 性质直接给出；平坦 ⟹ Γ=0 ⟹ 测地线方程 γ̈ + Γ(γ̇,γ̇) = γ̈ = 0 ⟹ γ̇ = v 常数。∎

**推论 PG-2a（谱扩散 = 天然测地段，精确化）**：谱扩散算子 L^W（u_feat = F⁻¹diag(W)Fu）是**线性映射**。对任意 u，其**线性插值**
$$\gamma(t) = u + t \cdot (u_{\text{feat}} - u), \quad t \in [0,1]$$
满足 γ̇ = u_feat − u（常数）⟹ γ 是 (ℂ^D, g_W) 的**匀速测地线段**（速度恒定、动能守恒）。**"段" = 从层输入 u 到谱扩散输出 u_feat 的线性插值**——这是执行方可直接实现的段定义。

### 19.3 分段测地线定理

**定理 PG-1（路径分解，B 级）**：设知识空间 M = M_glue ∪ S（胶水流形 + 离散骨架，AGG-14），则任意语义路径 γ: [0,T] → M 可分解为交替序列 {胶水段 γ_i ⊂ M_glue} ∪ {骨架跳变 s_j ∈ S}，满足：
- 段内：γ_i 为 (M_glue, g_W) 的**测地线段**（g_W-直线，线性演化）
- 段间：轨迹由 **Sinkhorn 路由重定向**（锚点 e_j 吸引，信息选择/压缩）
- 分解唯一性：由骨架点集 S 的位置（锚点布局）决定
- *依据*：AGG-14（胶水+骨架结构）+ AGG-15（拓扑不可嵌，连续路径无法穿过骨架）⟹ 路径在骨架处必须"跳变"而非"穿过"。

**定理 PG-3（路由 = 测地线重定向算子，C 级）**：Sinkhorn 软分配 π 将轨迹从一段测地线重定向到下一段：
- 段间方向跳变：‖Δv‖（速度/方向变化）由锚点吸引势决定——吸引势 = Sinkhorn 代价 C(u,e_j) = 1 − Re⟨u,e_j⟩/(|u||e_j|)（共轭内积实部，见 §4.5）
- 段间范数变化：路由聚合 ū = Σ π·u 的范数界 **‖ū‖ ≤ √(max_g s_g)·‖u‖**（**槽聚合路由集中度界**，s_g = Σ_i π_{i,g}；**非凸组合**——原"‖ū‖≤‖u‖"不成立，见 §11.1 关键修正）；路由集中时范数放大（均匀路由 D/G 倍、1-hot √D 倍）
- 段间能量有界：全块上界 (1+κ_f)^L 保持（DIS-4）——段内守恒 + 段间路由重定向 = 整体能量有界增长（AX6 兼容）

### 19.4 分段直线的架构内在性（训练正则降级）

**定理 PG-4（分段直线架构内在性，A 级，已验证）**：NMDN 内部单步算子均为"线性映射或保向缩放"，其一步插值天然是 g_W-测地线段：

| 单步算子 | 类型 | 插值 γ(t) = u + t(u′−u) |
|---|---|---|
| 谱扩散 L^W（O1'，§4.2） | 线性映射（u_feat = F⁻¹diag(W)Fu） | 匀速直线段（PG-2a） |
| modReLU（O2'，§4.3） | 保向缩放（σ(z)=s·z，s=ReLU(\|z\|+b)/\|z\| ∈ ℝ⁺） | 匀速直线段（方向不变） |

| 融合 u_out=αu_f+βu_s+u_r（O6'，§4.7） | 线性组合 | 匀速直线段 |

*证明*：线性映射/保向缩放 u → u′ 的插值 γ(t)=u+t(u′−u) 满足 γ̇ = u′−u 常数 ⟹ 测地线段（PG-2 定理 (iv)）。逐算子验证（上表）。∎

**推论 PG-4a（训练正则无必要）**：PG-1 的"段内测地线"是**架构内在性质**（无需正则强制）——离散轨迹天然为分段直线，段间方向突变仅来自路由重定向（PG-3）。**训练正则（g_W-直线偏差项）自动满足、无约束力，降级**：不作为训练损失，改为**验证监控**（PG-V2 测段内直线偏差应 ≈ 0，验证理论而非约束训练——实测 5.7e-6，理论证实）。

### 20.1 定理 T-DIM-1（C_D 等变下特征维不变性，A 级）

**陈述**：设 L: ℂ^D → ℂ^D' 与循环移位交换（L∘T_D = T_D'∘L），则：
- D' = D：L 为循环矩阵（频域对角乘子，T-GR-2）——唯一非平凡情形
- D' ≠ D 且 D ∤ D'：L ≡ 0（零映射）
- D' = mD（倍数）：L 为"嵌入补零"（旧 D 个特征空间嵌入，新 (m−1)D 维为 0）——**新维度无独立自由度，不增加信息**

*证明*：T_D 的特征值为 D 次单位根 ω_D^k（k=0..D-1，互异），T_D' 的特征值为 D' 次单位根。等变 ⟹ L 把每个 ω_D^k 特征空间映到 T_D' 的同特征值特征空间（否则 L 在该空间为 0）。ω_D^k ∈ {ω_D'^j} ⟺ D | D' 且 j ≡ k·(D'/D)（mod D'）——即仅当 D' 为 D 倍数时 D 个频率可嵌入，其余频率谱不匹配处 L 必为 0。∎

**推论 T-DIM-1a（直筒必然）**：NMDN 内部特征维 D 跨层不变——**"层间升维"在 C_D 等变框架下不存在**（非平凡升维映射不存在）。直筒式是 AX3 的直接推论，非工程简化。

**推论 T-DIM-1b（宽度在边界一次性买断）**：升维自由度全部集中在边界层 O0'（T-BOUND-1 自由）：输入 d_in → D 投影，D 即"神经束宽度"。类比：Transformer 每层临时雇 FFN 扩张（d→4d），NMDN 边界一次性招满（d_in→D），内部靠分工不分宽度。

### 20.2 三轴分化（替代 FFN 宽度扩张的分化机制）

| 分化轴 | 位置（算子） | 机制 | 对应 FFN 的 |
|---|---|---|---|
| 频率轴 | O1' 谱扩散（每层） | W_k 逐频率独立缩放——频率选择 = 信息筛选 | 特征选择 |
| 槽轴 | O4'→O5' 路由→槽聚合（每层） | 内容软分配分组（G 会议室）——主题分化、物理隔离 | MoE 专家分化（可微） |
| 状态轴 | O5' SSM 状态（每层） | 槽状态 h^(g) ∈ ℂ^N 递推——时间维记忆累积 | 注意力长程混合 |

**位置说明**：三轴全部在**每层内部**（CBlock 内），但分工不同——频率轴=单时刻特征分化（特征域）、槽轴=内容分组（语义域）、状态轴=时间累积（时间域）——三者正交，构成隐式高维分化（无需宽度扩张）。

### 20.3 合规扩张四路径（替代 FFN 升维）

1. **边界设大 D**（T-BOUND-1 自由，首选）：接入层投影 d_in→D，D 大 = 神经束空间更宽（当前 C-413 为 3072→128，是降维投影）
2. **增大 G×N**（槽数/SSM 状态维）：槽状态空间 G×N 隐式高维——标量参数形态，T-PAR-1 合规
3. **增加 L**（深度）：更多次混合+路由重定向（受 DIS-4/5 稳定性约束，需重标定）
4. **频域多尺度**（边界可选）：不同频带分组处理

### 20.4 与 EXP-11 的联系（D>1 是相位语义前提）

d=1 崩盘的深度归因（EXP-11，2026-08-08）：① 无跨束混合（FFT 恒等）——相位无法进入幅值（除 SSM 复数求和干涉的弱通道）；② 无相对相位（U(1) 规范自由下绝对相位无信息，DIS-3）；③ 输出侧幅值读出秩 1 + 分桶不可微——相位分化信号极弱。**结论：D>1 的频域混合是相位语义（AX5）的前提**——相对相位模式（D 维方向）经 FFT 混合承载类别。

### 21.4 路由 = Hopfield softmax 检索同构（PG-5，推演层，B 级）

> **编号说明**：本定理在白皮书 v5.8 以 **PG-5** 登记（路由=Hopfield 检索同构，β=1/λ，推演层，验证前置）——旧 MF §16.4 正文未标号，4.0 补齐编号保持全项目一致。

**同构（显式，非类比）**：NMDN 路由 π = softmax(−c/λ)，c = 1 − Re⟨u,e⟩/(|u||e|)。softmax 平移不变（加常数 −1/λ 不影响分配）⟹

$$\pi_{i,j} = \mathrm{softmax}\Big(\frac{1}{\lambda} \cdot \frac{\mathrm{Re}\langle u_i, e_j\rangle}{|u_i|\,|e_j|}\Big) = \mathrm{softmax}\big(\beta \cdot \cos(u_i, e_j)\big), \quad \beta = 1/\lambda$$

锚点归一化（|e_j|=1，当前实现）且 u 经 CNorm 后 |u|=1 ⟹ π = softmax(β·Re⟨u,e_j⟩)——与 Hopfield 检索概率 p(ξ_j|x) = softmax(β⟨x,ξ_j⟩) 显式同构（β=1/λ，归一化内积）。

**容量下界推演（锚点设定专属，不可直接套用 Ramsauer 定理 3）**：
- Ramsauer 2020 定理 3 的指数容量 P=exp(αN) 假设**存储矩阵 W=ΞΞ^T 的迭代检索收敛**（谱结构条件）；NMDN 锚点即模式、**单次 softmax 检索**（无存储矩阵、无迭代）——**不能直接借用**，Ramsauer 仅为"softmax 检索动力学容量"的灵感来源
- 锚点设定下的下界推演（待数值验证）：给定类别数 M、锚点维 d_a、可靠度 ε，"每类至少一个可靠检索锚点" ⟹ G_min ≥ f(M, d_a, ε)——具体形式待推演+随机模拟验证（复用 V-2b 方法论）
- **验证协议**：随机锚点/任务模拟，绘制"检索可靠度 vs G、d_a、λ"曲线与定理匹配——**通过前不得用于 G 取值**（守则 R1）
